# factory-sample-django (Backend): mission

## What it is

A small task tracker API built with Django 5.1 and Django REST Framework on SQLite. It manages projects, tasks (with status, priority and due date) and comments.

It is a sample repository for onboarding into the Software Factory. It exercises the repository scan, mapping tests, feature stories, migrations and bug triage on a real Python project before client repositories are onboarded.
